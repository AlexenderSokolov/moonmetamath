## 项目简介

MoonMetamath 为 MoonBit 程序提供可直接调用的 Metamath 证明检查和逐步执行能力。开发者可以加载标准 `.mm` 数据库，检查普通证明与压缩证明；学习者可以在浏览器中从空栈构造证明，观察代换、假设和栈的变化；外部程序可以提交证明动作，由确定性的检查器判断每一步是否合法，并将完成的证明导出为标准文件。

项目交付 Mooncakes 原生库、Node CLI、浏览器证明实验室和独立下游接入示例。数学判断集中在同一个 MoonBit 内核中，网页与命令行负责输入、展示和交互。运行发行程序不需要 Python、C 检查器或模型凭据。

## 解决的问题与使用场景

**MoonBit 开发者接入形式化验证。** 外部项目从 Mooncakes 安装库后，通过公开接口加载数据库、验证前提、创建会话、执行动作和导出证明。独立示例已在注册表安装环境下运行，展示两个引擎互不影响、会话反复释放复用以及证明导出，便于其他项目直接参考。

**形式证明学习和调试。** 用户在网页选择示例或上传文件，可以查询可用规则、预览一步、撤回操作、保存与恢复工作。错误步骤保留原状态；新目标或文件恢复失败时，原工作仍可继续。规则所需的假设、代换结果和不交变量条件有明确展示。

**AI 证明动作的确定性检查。** 模型或搜索程序只负责提出候选动作，内核负责验证。项目已有固定十道自编小题的真实补全实验，所有成功候选经过独立检查器复核。该实验用于说明接口能够连接模型，不作为标准评测优势或新数学成果的依据。

## 核心功能与技术实现

- 支持 Metamath 声明、作用域、include、必要假设、不交变量约束、普通证明与压缩证明。
- 解析与验证分开；尚未验证的定理、当前目标自身和未来定理不能作为可信前提。
- 普通证明、压缩证明与交互动作共用执行器，减少多套实现之间的语义偏差。
- 提供独立引擎、会话关闭和数据库卸载。活动会话存在时明确拒绝卸载，过期句柄不能重新指向其他对象。
- 保留 schema 1、旧 dispatcher 和原生接口；旧工作文件通过重新检查源文件、重放动作恢复。
- 将完成的普通构造证明导出为自足 `.mm` 文件，可交给独立 Metamath 工具再次检查。

## MoonBit 生态价值与长期维护

项目的复用价值在于原生库与公开接口：MoonBit 项目可以直接使用检查器，CLI 和网页又提供了可实际操作的入口。其他语言的成熟实现被用于规范理解、移植参考和独立对照。

维护中已经采用固定工具链、版本化接口、冻结的旧工作文件、独立消费者测试，以及 Windows／Linux CI。浏览器测试覆盖资源生命周期、失败恢复、取消和下载，站点部署使用经过测试的制品。后续优先依据真实下游需求完善诊断、接入和容量边界。

## 实际验证与性能结果

0.4.0 的本地检查包括 JS、wasm-gc 各 69 项核心测试、70 项宿主测试、79 项固定外部样例及独立参考对照。三份完整真实数据库固定于同一官方提交，分别为 `hol.mm` 的 151 个证明、`nf.mm` 的 5,976 个证明和 `set.mm` 的 48,097 个证明，原文件均由官方 C 检查器独立验证。

性能比较来自同一台 Windows／Node 24 机器，每个完成单元使用三个独立进程样本。下表为同预算比较的中位数，RSS 包含整个 Node 进程。

| 数据库与配置 | 加载耗时：0.3 → 0.4 | 峰值 RSS：0.3 → 0.4 |
|---|---:|---:|
| hol，512 MiB V8 old-space 额度、默认操作预算 | 22.08 → 24.43 ms | 66.07 → 59.89 MiB |
| nf，512 MiB V8 old-space 额度、默认操作预算 | 262.25 → 211.46 ms | 304.62 → 148.55 MiB |
| set，2048 MiB V8 old-space 额度、明确一亿操作预算 | 4545.24 → 3452.27 ms | 1908.80 → 749.70 MiB |

测量发现加载阶段存在整份字符数组、全文件 token 驻留和重复上下文复制。0.4 针对这些分配改用按声明消费 token 和私有不可变上下文复用，同时保留完整词法预检与公开扫描接口。中库、大库的峰值 RSS 中位数分别约降低 51% 和 61%。小库加载略慢，验证阶段没有可靠的加速结论；完整范围与失败记录见 [性能报告](PERFORMANCE.md)。

完整 `set.mm` 已在 512 MiB V8 old-space 额度、明确一亿操作预算下完成三次全库验证，峰值 RSS 中位数为 692.02 MiB。old-space 额度不等于总进程内存上限。默认一千万操作预算保持不变，仍会如实报告超限。完整大库的新目标流程在已测 512／2048 MiB 配置下仍未完成，是后续需要解决的容量边界。

## 演示与复现

1. 打开在线实验室，选择“两步构造”练习，依次应用 `wph` 和 `identity`，检查完成并下载证明。
2. 选择不交变量练习，尝试不满足约束的动作，查看错误及原状态，再撤回并完成合法构造。
3. 保存部分工作、重新载入并继续证明，展示失败恢复对原工作的保护。
4. 从源码运行独立下游示例，展示引擎隔离、80 次会话复用和独立导出检查。

```sh
moon add AlexenderSokolov/moonmetamath@0.4.0
node scripts/check.mjs
node scripts/downstream.mjs --registry --version 0.4.0
```

开发复现需按 README 安装固定工具链和参考材料；性能输入下载与测量命令见 [benchmark 说明](../benchmarks/README.md)。发行包可以只用 Node 24 运行。
